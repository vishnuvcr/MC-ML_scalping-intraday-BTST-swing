# Project Research Instructions

This repository follows a finite, auditable research protocol for Monte Carlo, scalping, intraday, BTST and swing studies.

Rules: separate phases/branches; manual Actions workflow per phase; cache third-party data where permitted; keep raw data out of the repo unless licensed; version provenance/cost assumptions; include brokerage, statutory charges, spread and slippage; use strict train/validation/test splits; log all material errors; update phase status and decision logs; do not promote single-symbol or single-regime results; stop at the finite evidence gate; produce a structured manuscript with methods, statistics, results, limitations and future research.

Conversation log policy: keep a concise reproducible decision/outcome trace. Private chain-of-thought is never copied into repository files.
