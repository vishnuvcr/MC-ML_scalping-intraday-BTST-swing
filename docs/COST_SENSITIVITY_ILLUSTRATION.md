# Cost Sensitivity Illustration

These are arithmetic illustrations, not trading results. They use the provisional Rs 20/order brokerage input and current public NSE levy rates documented in COST_MODEL_2026.md.

For a ₹100,000 buy and ₹100,000 sell:

| Mode | Statutory + brokerage, before spread/slippage | With 2 bps spread + 3 bps slippage on each leg |
|---|---:|---:|
| Intraday | ₹82.68 | ₹182.68 |
| Delivery/BTST/swing | ₹269.68 | ₹369.68 |

The delivery figure is dominated by the 0.10% STT on both delivery purchase and sale. The intraday case has STT only on the sell side under the current NSE schedule. citeturn350019search0
